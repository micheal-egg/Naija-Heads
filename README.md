# 📱 Naija Heads Up
*A Nigerian-themed party guessing game built in SwiftUI.*

Naija Heads Up is an iOS game inspired by the classic “Heads Up!” but tailored for Nigerian culture.  
Players hold the phone to their forehead while friends give clues based on Naija slang, Afrobeats artists, Nollywood stars, foods, locations, and more. Tilt down for **Correct**, tilt up for **Pass**, and rack up points before the timer ends!

---

## 🎯 Features

- 🇳🇬 **Nigerian-themed card decks** (slang, artists, food, Nollywood, etc.)
- ⏱️ **60-second timed rounds**
- 🔄 **Card rotation + scoring**
- 🎮 **Correct / Pass controls** *(tilt detection coming soon)*
- 🎨 **Clean SwiftUI UI** with gradients and modern animations
- 📂 **Modular architecture** (Models → Views → Game Logic)
